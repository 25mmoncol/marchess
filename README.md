# MarChess

## Run in VS Code
1. Install Node.js 20 or newer.
2. Open this folder in VS Code.
3. Open Terminal → New Terminal.
4. Run: npm start
5. Open http://localhost:3000 in chrome



No API key. It uses pulbic stockfish 19

In Settings, enable **Show opponent's best reply** to show one pink arrow for the opponent's best response after Stockfish's suggested move. This optional feature is off by default: it shows an initial reply after 0.5 seconds, then updates it while Stockfish searches for another 2.5 seconds.
